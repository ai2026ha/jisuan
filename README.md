# 代理计算中心（UI测试版）

这是按当前需求制作的 Windows 浏览器版 Demo。

## 启动
Windows 双击 `启动系统.bat`。
首次运行会自动创建 `.venv` 并安装依赖，然后打开浏览器。

默认账号：
- 用户名：admin
- 密码：admin123

## 固定公式
游戏新增时绑定：
1. 数字 × 0.94 × 0.50
2. 数字 × 0.94 × 0.55
3. 数字 × 0.94 × 0.45

添加后不修改公式。计算时：
`自定义数字 × 游戏绑定公式 ÷ 汇率`

## UI
- 左侧导航
- 今日概览
- 每个代理独立账单卡片
- 每次计算在对应代理下新增一条记录
- 记录显示：游戏名 + 实际计算式 + 本次结果
- 结果自动累计到代理总额
- 代理清零不删除历史
- 全选自动跳过 <50
- 今日 TXT 导出自动跳过累计 <50

注意：这是测试版，首次运行建议在空目录中使用。


## 如果双击后窗口一闪而过
不要直接双击，也可以在项目文件夹地址栏输入 `cmd` 后回车，再运行：
`启动系统.bat`
这样能看到具体错误信息。

如果 Windows 没安装 Python，先安装 Python 3.10+，安装时勾选 `Add Python to PATH`。


V3启动器会单独打开服务器窗口，并等待 127.0.0.1:8000 真正可用后再打开浏览器。如果服务器启动失败，服务器窗口会保留错误信息。
